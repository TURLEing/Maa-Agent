# 退出当前战斗

`cancel` 只停止执行器，游戏可能仍在战斗。需要放弃当前对局并准备重开时使用：

```powershell
python -m maa_agent exit-battle --run-id RUN_ID --expected-stage H8-4
```

命令等待指定执行器停止，取得设备独占锁，然后逐屏识别并完成：打开退出菜单、确认放弃、关闭失败提示和结算、返回并核验指定关卡准备页。不会开始下一场战斗；放弃对局可能消耗正常理智，返还情况以游戏规则为准。

- 没有 harness 任务时可省略 `--run-id`；如果其他执行器仍占用设备，命令会拒绝操作。
- 省略 `--expected-stage` 时停在已核验的非战斗页面。关卡导航限当前章节，不能跨任意章节。
- 只有 `exit_verified:true` 表示退出已确认；指定了关卡时，还必须检查 `stage.stage_verified:true` 才能重开。
- 返回 `error` 时命令退出码为 1。`exit_succeeded_but_stage_not_verified` 表示已经退出，但未确认返回目标关卡。

执行器停止等待最多 30 秒，退出观察循环最多 90 秒；单次底层识别可能额外耗时。放弃确认只点击一次；结算动画可能吞掉点击，因此重新观察后最多尝试三次，间隔至少三秒。未知页面不盲点，退出失败返回 `exit_verified:false`，不声称战斗已经停止。

观察截图和退出步骤保存在 `.runtime/observations/` 与 `.runtime/navigation/<id>/exit.json`，可通过返回的 `evidence_dir` 查看。错误目标关卡也会保留退出证据。

当前覆盖国服普通战斗、暂停、放弃确认、失败提示与普通结算页面，已在 MuMu 上调试。代理解锁/保存阵容弹窗及特殊活动弹窗尚未纳入此流程；遇到这些页面应检查证据并单独处理。测试覆盖退出状态转换、未知页面不点击、重复画面、结算重试上限和任务取消。
